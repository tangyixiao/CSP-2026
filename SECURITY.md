# Security

Report a website or automation vulnerability using the repository's private
[security advisory form](https://github.com/tangyixiao/CSP-2026/security/advisories/new).
Include the affected URL or workflow, reproduction steps and expected impact.
Do not put credentials, extraction passwords or private data in public reports.

Contestant submissions are preserved as archive materials. They are not executed
as part of archiving. For missing files, provenance questions or code discussion,
use Issues or Discussions rather than a private vulnerability report.

The website supports the currently deployed main branch. Fixes are verified in
CI before deployment. A release identifies the exact archive commit and checksums.
