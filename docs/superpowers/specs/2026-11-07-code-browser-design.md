The existing tangyixiao/CSP-2026 archive is the source of truth. Add a static code browser using Monaco for C++ highlighting, read-only source viewing, side-by-side and inline diff, next/previous change, whitespace comparison, copying and shareable links. Keep the existing Pages landing and documentation available, and add this tool under `code/` with visible navigation from the landing.

The browser indexes archived contestant source paths by province, group, contestant and problem. Generate per-group JSON catalogs from a pinned Git commit without rewriting contestant files. Build same-origin source packs keyed by Git blob ID, preserve bytes in base64, and verify the Git blob digest in the browser before decoding UTF-8 or GB18030. Cap previews at 2 MiB and expose original GitHub links. This avoids the observed raw.githubusercontent.com connection failure. Never execute submissions.
