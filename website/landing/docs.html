查找选手文件

在浏览页将范围设为“全国统一”“固定省份”或“多省合并”，再选择 J/S 组别。输入考号、题目或文件名即可搜索，也可按文件数、字节数等排序。打开选手文件夹后，可查看全部文件和子目录。

按省份打开仓库目录
省份 入门组 J 提高组 S
各省 J / S 组目录以源码仓库的实际目录为准。

阅读与比较

点击文件旁的“阅读”打开原文；选择两份文件“加入比较”后，可查看并排或内联差异。二进制文件使用十六进制视图。

C/C++ 默认显示原文。点击“格式化 C/C++”开启格式化；展开“编辑 .clang-format”可修改、导入或导出配置。应用配置会开启格式化显示，可点击“显示原文”返回。格式化可能改变显示行号，复制仍取原文，下载保留归档字节。

下载与校验

下载单个文件时，在阅读页选择“下载文件”；保存整位选手的文件时，在选手文件夹中选择“下载选手目录 ZIP”。单文件在线预览上限为 2 MiB，浏览器打包上限为 64 MiB；超出时使用原文件链接或地区归档包。

Git 不记录空目录；需要恢复官方压缩包中的完整原貌时，请解压对应的 answers.zip。

下载后可按 SHA-256 指南校验。文件来源和统计口径见来源说明。

参与讨论

在阅读页打开评论，登录 GitHub 后即可参与。评论区加载失败时，可直接前往 GitHub Discussions。
