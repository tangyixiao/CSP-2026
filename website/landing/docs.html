CSP-2026#

这里归档 CSP-J/S 2026 第二轮公开的选手代码，按省份和组别整理。目录中的考号、题目名和选手文件保持原样。

省份 普及组 J 提高组 S
各省 J / S 组目录以源码仓库的实际目录为准。

各组代码按省份、组别、考号和题目组织。目录结构与文件名保留在归档中；代码浏览器按本次构建的 Git 提交建立索引，支持查看原始代码与并排比对。

浙江 J、S 组的官方原始压缩包和选手答案概要信息分别保存在 ZJ/J/ 和 ZJ/S/。公告来源见 ZJ/sources。Git 不记录空目录；需要恢复官方压缩包中的完整原貌时，请解压对应的 answers.zip。

浙江 J 组曾与官方压缩包逐文件对照；其他省份未逐一核对官方原件。官方测试数据见 test-data/J/official 和 test-data/S/official。本仓库不包含官方评测成绩。

在线浏览与讨论

进入代码浏览与比对，选择归档文件或材料中的案例，查看 VS Code 同源编辑器提供的 C++ 高亮与并排差异。材料原帖、原始代码和相似性观察应分别核实；原帖中的判断不等于官方结论。

页面通过 giscus 嵌入 GitHub Discussions。访客可在评论区使用自己的 GitHub 账号授权后评论；讨论保存在 GitHub，网站不接收 GitHub 密码。若评论区未加载，可直接打开 Discussions。

目录与原始源码字节快照固定到本次构建的 Git 提交，并从本站加载，首次访问无需连接 raw.githubusercontent.com。单文件预览上限为 2 MiB，更大文件请打开 GitHub 原文件。没有采集源码字节大小的字段不应解释为零；源码加载后的字节相等或字符差异指标只能描述文本，无法单独证明行为原因。
