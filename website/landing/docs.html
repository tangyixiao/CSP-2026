CSP-2026#

这里归档 CSP-J/S 2026 第二轮公开的选手代码，按省份和组别整理。目录中的考号、题目名和选手文件保持原样。

省份 普及组 J 提高组 S
各省 J / S 组目录以源码仓库的实际目录为准。

在浏览页选择全国、单省或多个省份，按考号、题目或文件名查找选手。打开文件夹可查看该选手的全部文件和子目录。

Git 不记录空目录；需要恢复官方压缩包中的完整原貌时，请解压对应的 answers.zip。

在线浏览与讨论

打开文件后可阅读代码，或将两份文件加入比较，查看并排与内联差异。默认显示原文；C/C++ 格式化可手动开启，.clang-format 配置支持编辑、导入和导出。二进制文件使用十六进制视图。

评论区连接 GitHub Discussions，登录 GitHub 后即可参与。评论区加载失败时，可直接打开讨论页。

单文件在线预览上限为 2 MiB，浏览器生成选手目录 ZIP 的上限为 64 MiB。超出时使用原文件链接或地区下载包。下载后可按 SHA-256 指南校验。来源和统计口径见来源说明。
