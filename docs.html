CSP-2026

这里归档 CSP-J/S 2026 第二轮公开的选手代码，按省份和组别整理。目录中的考号、题目名和选手文件保持原样。

省份 普及组 J 提高组 S
安徽 AH — AH/S
北京 BJ — BJ/S
广西 GX GX/J —
河南 HA HA/J HA/S
湖北 HB HB/J HB/S
湖南 HN HN/J HN/S
江苏 JS JS/J JS/S
辽宁 LN — LN/S
山东 SD — SD/S
陕西 SN SN/J SN/S
天津 TJ TJ/J TJ/S
浙江 ZJ ZJ/J ZJ/S

各组代码位于相应组别下的 选手代码/考号/题目/。

浙江 J、S 组的官方原始压缩包和选手答案概要信息分别保存在 ZJ/J/ 和 ZJ/S/。三个浙江官方公告的标题、时间、原文数据和链接见 浙江网页来源。Git 不记录空目录；需要恢复浙江官方压缩包中的完整原貌时，请解压对应的 answers.zip。

浙江 J 组已与官方压缩包逐文件对照；其他省份尚未逐一核对官方原件。本仓库不包含官方测试数据或官方评测成绩。

当前移动硬盘上的工作区只展开了浙江 S 组选手代码与浙江官方原件，其余代码保存在本地 Git 对象中。需要展开例如江苏代码时，在仓库目录执行：

git sparse-checkout add '/JS/'

需要展开浙江 J 组选手代码时：

git sparse-checkout add '/ZJ/J/选手代码/'

展开前请留意移动硬盘的剩余空间；文件数量很多，当前文件系统的小文件会占用较多空间。
